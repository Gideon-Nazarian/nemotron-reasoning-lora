# Experiments

Structured ledger of every submission. **Source of truth for "have we tried this combo?"** — scan this file before designing a new experiment.

> Note for the public copy: many rows cite notebooks (v12 and v13 onward, plus bank/warm-start/repackage kernels), datasets and notes that are not included here. Most of those notebooks were modified copies of other competitors' public notebooks, and the generated corpora and per-problem outputs contain competition data. The ledger is kept as the record of what was run. See the README, "What is not in this public copy".

## Schema rules

- One row per submission. Never edit a past row except to append to `Takeaway`.
- `git_commit` is mandatory (short hash; the notebook used must be committed before submitting).
- `Seed` is mandatory (project default = 42).
- `Local eval` column populated from Week 1 onward; before that, `n/a (no harness yet)`.
- `Takeaway` is required and includes ≥ 1 categorized failure mode drawn from looking at 5-10 wrong predictions. Aggregate score alone is not a takeaway.
- Format of takeaway: `delta vs prior; failure modes: <category1>, <category2>`.
- Before any new experiment: scan this file to confirm we haven't already run that combo.
